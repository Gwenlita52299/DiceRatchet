## 你的唯一目标

## 你要先知道的六个事实

1. 起点 harness 是 **v4**（`harness/version.json.version == 4`，`play_hash` 应以
   `sha256:1ebe12e1` 开头）。它已过门禁（`accepted_by: human`），起点守卫会放行。
2. 正式轮的参数**全部来自 `configs/default.yaml`**：`evals.n_heldout=40`（H1）、`loop.k=30`、
   `evolve.min_heldout_n=20`、`evolve.hitl=true`、`evolve.n_candidates=1`。**不要**用环境变量覆盖它们。
3. 当前可演化键是 4 个（`sampling.temperature`、`sampling.memory_top_k`、`prompt.token_budget`、
   `policy.retry_max`），其中前两个是**训练侧**，eval 轮次里提案方只能看到后两个。
4. `loop.k` 必须等于 `train.per_generation`（30）。跑到 30 局时触发且只触发 1 次演化；
   只给 30 个种子，所以本 run 只有 1 代。
5. 预算与时长：**≈5 h、≈¥64**（gen-000 基线 40 局 ≈¥21/100 min；30 局训练 ≈¥22/95 min；
   候选 40 局 heldout ≈¥21/100 min）。如果走「复用 m3r4 的 gen-000」（见步骤 2），省 ≈¥21/1.7 h，
   总计 ≈3.4 h、≈¥43。
6. 结束时 `loop run` 会以 **exit 0 + `phase=hitl_wait`** 挂起（这是成功，不是失败）。

## 步骤 4：怎么判断跑完了

三种终止形态：

| 现象 | 含义 | 你要做的 |
|---|---|---|
| `state.json` 里 `"phase": "hitl_wait"`，且存在 `generations/gen-001/gate.json` | **成功**：候选已评估完，等人裁决 | **停下**，报告（见下），不要 approve |
| `"phase": "done"`，`generations/gen-001/report.json.decision == "reject"` | 本代被拒（可能是 C1/C2/C5 或 `no_candidate`） | 停下，报告 |
| 进程消失但没有 `phase` 更新、日志有 traceback | 故障 | 保留日志，报告 |

```bash
ls runs/m3r5/generations/gen-001/
.venv/bin/python - <<'PY'
import json, glob
d = json.load(open("runs/m3r5/generations/gen-001/report.json"))
print("decision:", d.get("decision"), "| reason:", d.get("reason"))
print("heldout:", {k: (d.get("heldout") or {}).get(k) for k in ("n","win_rate","source")})
for c in d.get("candidates") or []:
    print("cand:", c.get("kind"), c.get("decision"), "|", c.get("reason"))
p = glob.glob("runs/m3r5/generations/gen-001/candidates/*.json")
if p:
    v = (json.load(open(p[0])).get("verdict") or {})
```

## 常见故障与处置（不要自行绕过）

| 错误 | 处置 |
|---|---|
| `E_IO_GIT_DIRTY`（退出码 4） | 工作区不干净。停下，把 `git status --porcelain` 报告给人类 |
| `E_EVOLVE_UNGATED_START`（退出码 2） | 起点 play 面没被判定过。检查 `harness/version.json.version`；**不要**加 `--allow-ungated-start` |
| `E_IO_RUN_CONFLICT` | `config_hash` 与已有 run 不一致（或 `--k` 与 state 不一致）。停下报告，换 run-id 由人类决定 |
| `E_EVOLVE_NO_CANDIDATE` | 提案没产出合法候选（3 次重试后）。照常报告：report 里 `reason=no_candidate`，这一代没花钱评估 |
| `E_LLM_*` / 网络 | 用 `--resume` 重试同一命令；连续失败则停下报告 |
| 进程被杀 | 同环境变量 + `--resume` 续跑（不会重跑已完成的局） |
