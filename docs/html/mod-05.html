MOD-05 memory

反射注入的落地载体。它把局末反思转成结构化记忆，按当前局势检索回 prompt；同时是 INV-5 在本项目里最难守的一环——因为“记忆”天生喜欢把见过的 seed 记下来。

L1 智能体 ✅ 已落地 INV-5 四拦截点 逻辑时钟 tick

01写入管线：从一段反思到一条记忆

去重与冲突都是确定性的。相似度、引用数、胜负差都有明确阈值；LLM 只用于可选的候选抽取，失败即退回规则抽取，反思仍然入库。

02读取管线：按“现在的局面”取记忆

检索打分为五路加权，再按 token 预算裁剪；顺序必须确定（同分按 id 升序），否则 prompt 不可复现。

信号权重（默认）作用
tag 命中1.0失败原因 / 局面标签的精确匹配
BM250.6文本相似（k1=1.2, b=0.75）
向量0.0可选；默认关闭（不引入额外模型依赖）
效用0.3只用环境原生胜负的证据（INV-7）
时新度0.1exp(−Δticks/…)，recency_lambda=0.01

检索参数：top_k=8、token_budget=900、min_score=0.15、同局面加成 0.25。返回前对入选条目做 I4 廉价复检：命中条目丢弃并记事件，不计入返回。

“同局面加成”是确定性的。SituationKey 由阶段、学派、心数区间等离散字段组成；不用 embedding 相似度决定是否同局面，避免不可复现。

03INV-5：四个拦截点，缺一不可

为什么需要四个。入口能挡新写入，但挡不住旧快照、手工导入与“文本里换个写法”；I3 在出快照时复扫全库，I4 在每次返回前复检，才算闭环。

04时间与容量：逻辑时钟，不用墙钟

tick = 已完成的训练局数

由 MOD-06 维护，写入 state.json。TTL、时新度、淘汰全部以 tick 为唯一时间源——重跑与续跑不会因为“今天几号”改变结果。

容量 2,000 条

ttl_ticks=300、min_age_ticks=30、compact_every=200。淘汰时保护「引用 ≥3 次或太新」的条目。

快照与回滚

memory_v{N}.jsonl + 索引；回滚缺失 → E_IO_SNAPSHOT_MISSING（退出码 2），sha 不符 → E_IO_MEMORY_CORRUPT。

效用分只用原生胜负

# PRD §6.4：Laplace 平滑后的“被采纳 vs 未被采纳”胜率差
p_used = (n_win_adopted + 1) / (n_adopted + 2)
p_base = (n_win_not_adopted + 1) / (n_not_adopted + 2)
utility = clip(0.5*(p_used - p_base)
             + 0.3*log1p(n_ref)/log1p(200)
             + 0.2*exp(-age_ticks/ttl_ticks), -1.0, 1.0)

adopted 由 MOD-04 判定并经 DecisionResult.adopted_memory_ids 传给 MOD-06；MOD-05 不做语义判断。
