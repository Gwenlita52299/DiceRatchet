GAME RSI · MODULE WALKTHROUGH

GameRSI 模块讲解系列

GameRSI 是一个「自我改进（RSI）游戏智能体」研究项目：agent 在一局卡牌游戏里做决策，每隔 K 局改写自己的 harness，再由环境 ground-truth 决定改动去留。整套系统被拆成 9 个有明确上下游纪律的模块（MOD-01 ～ MOD-09），每个模块一份技术 PRD，本系列把它们讲成新人能读的讲解页。

9 个模块4 个层级 L0–L3每页 17 节：背景 / 范围 / FR / NFR / 接口契约 / 流程 / 配置 / 错误码 / 测试 / DoD
怎么读：从 MOD-01 / MOD-02（环境层）入手理解「游戏事实从哪来、agent 只能看到什么」，再看 MOD-03/04/05（智能体层）理解决策如何产生，然后 MOD-06/07（进化层）看闭环如何自跑，最后 MOD-08/09（测量与工程层）看改进如何被证伪、全链路如何可复现。所有页共享同一套侧栏导航，可互相跳转。

L0 · 环境层 —— 游戏事实的唯一来源

MOD-01 · M0

环境规则内核

env-rules · gamer_rsi/env/

GAME 内核的纯 Python 等价移植。不定义任何游戏规则——规则、数值、配表全部引用 GAME；唯一目标是给定同一配表、同一 config、同一动作序列，与 JS 内核逐字节相等。

逐位等价golden 对拍确定性
MOD-02 · M0

环境沙箱

env-sandbox · gamer_rsi/sandbox/

L0 与 L1 之间唯一合法数据通道。三条独立防线：投影裁剪防泄漏、代码/进程隔离防越权、审计与蜜罐防未被发现的泄漏——「agent 只能看到它该看到的」。

投影 schema 登记受限执行器蜜罐 canary

L1 · 智能体层 —— 每回合决策

MOD-03 · M1

推理层

inference · gamer_rsi/inference/

L1 层唯一的「模型出口」：把 Mac M5 24GB 全程离线的本地推理收敛为可测、可复现、可降级的接口，屏蔽 MLX / llama.cpp 差异，收口 JSON 语法错误与 OOM。

generate_json 三级降级同 seed 逐字节一致E_LLM_OOM 可捕获
MOD-04 · M1

策略层

policy · gamer_rsi/agent/

把 Observation 变成 prompt、把 LLM 原始文本变成 Action。模型再离谱也不污染环境与指标：三级校验、每步重试、连续非法判负，故障一律退化为可解释的启发式动作。

prompt_hash 可复现illegal_rate ≤ 0.02（M3 判定）启发式 fallback
MOD-05 · M2

记忆层

memory · gamer_rsi/memory/

L1 层的策略记忆与反思库：把局末反思转成可检索、可度量、可淘汰、可回滚的结构化记忆，供组装 prompt 时按当前 Observation 取用；heldout seed 永不进入记忆。

BM25 + 效用打分memory_v{N} 快照回滚INV-5 四拦截点

L2 · 进化层 —— 让闭环自跑

MOD-06 · M2

训练循环

loop · gamer_rsi/loop/

L2 的编排器：自己不产生策略、不训练模型，只让 play → evaluate → reflect → evolve 这条闭环在一局、K 局、一代三个时间尺度上正确、可复现、可中断、可恢复地跑起来。

局/周期双层调度run 级续跑反思降级不阻塞
MOD-07 · M2→M3

演化层

evolve · gamer_rsi/evolve/

RSI 闭环中最危险的一段：让 agent 改写自己的 harness，并由环境 ground-truth 决定改动去留。设计重心不是「更聪明的改动」，而是在结构上掐死自我确认环路。

生成者/裁判上下文不重叠verdict 防过拟合版本门禁 + 回滚

L3 · 测量与工程层 —— 可证伪与可复现

MOD-08 · M1→M3

评估层

evals · gamer_rsi/evals/

L3 测量层，只读轨迹与报告、不参与决策。唯一理由是让「自我改进是否真的发生」成为可复现、可审计、可证伪的数字：主指标只用环境原生胜负，heldout 严格隔离，熵曲线盯防坍缩。

win_rate 主指标real_gain vs overfit_suspectcollapse_flag
MOD-09 · M0–M3

基础设施

infra · gamer_rsi/infra/

依赖矩阵里唯一不被任何人阻塞、却阻塞所有人的模块。M0 第一天就要有配置、日志、CLI 与确定性守卫——否则可复现性与 INV-6 从第一天就失效。
