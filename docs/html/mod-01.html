MOD-01 env-rules

游戏规则的纯 Python 等价内核。它不发明任何规则，只负责让同一份配表、同一个 seed、同一串动作，在 Python 里得到与 JS 内核逐字节相同的状态、观测与随机流。

L0 环境 ✅ 已落地 零依赖 · 只用标准库 被 MOD-02 独占调用

01为什么需要一份“翻译过的内核”

智能体链路（MOD-02～08）全部是 Python。如果训练时经 HTTP 调 JS 游戏，会引入进程边界、网络栈与额外延迟，更难保证“同一 seed 两次跑出同一结果”。所以游戏本体先在 JS 里做成可玩的网页版（GAME 系列），再把规则内核按同一契约搬到 Python。

不定义规则

规则、数值、配表的唯一事实来源是 GAME-00/01/02 与 src/game。MOD-01 只做移植，冲突时以游戏侧为准。

只承诺对拍

承诺的是三个摘要：obsDigest / rngDigest / stateDigest 与 JS 逐字节相等，而不是“看起来像”。

零运行时依赖

只用标准库；唯一例外是 env/selftest.py 只读 infra.guards。env 层目前不在 MOD-09 分层守卫的覆盖内，靠 env selftest 与 golden 钉住。

02双内核对拍：一份规则，两种语言

对拍不是抽样。g5 的 1,487 个 env 步是 CI 的硬基线；Python 侧任何一步的摘要漂移都会让整条流水线变红。

03一步动作在内核里发生了什么

非法动作不是异常。内核按 GAME-01 §4 的语义返回 illegal=True 与原因；真正的失败（内核异常 / 不变式违反）才走 E_ENV_INTERNAL。
  1. 写时构造。先复制再修改，入参 state 永不被原地改写——这让「同一状态分叉两次」成为可能，也让轨迹可重放。
  2. 顺序固定。legal_actions 的元素与顺序必须与 JS 完全一致；MOD-02 据此只做减法（去掉 abandon_run）。
  3. 整数算术。禁止 / 与 int() 截断，千分倍率用整数运算，位运算后强制 & 0xFFFFFFFF，以对齐 JS 的 32 位语义。

04确定性三件套

stable_stringify

递归排序键、ensure_ascii=True、紧凑分隔符；出现 float 直接抛错。摘要因此与语言、平台、locale 无关。

digest(v)

"sha256:" + sha256(stable_stringify(v))。sha256 只用于摘要，不参与随机数派生。

SplitMix64 + 16 位分片

xmur3(streamName) 与 rootSeed 混合后派生；8 条流固定为 dice.enemy, dice.player, event, forge, levelup, loot, map, shop。

摘要覆盖什么谁在消费
obsDigest白名单投影后的 Observation（不含 seed）MOD-02 投影对拍 / golden
rngDigest8 条随机流的状态与计数确定性审计（INV-6）
stateDigest完整 GameState（含隐藏信息）轨迹审计 / 重放 / 双跑比对

05边界：谁能碰内核

INV-1 的落点。L1+ 只能拿到 MOD-02 投影后的 Observation；直接 import 内核会被 CI 静态门禁与运行期 import hook 双重拒绝。

06配置与错误映射

本模块不定义游戏参数：难度、开关、局长由 EpisodeConfig 经 env.episode.* 传入。历史上有三个“死键”（env.content_dir / env.golden_dir / env.check_invariants），已于 2026-10-14 删除——配表目录的权威是 loader.GAME_CONTENT_DIR。

JS 码Python 码含义
E_KERNEL_BAD_CONFIGE_ENV_CONFIG_INVALID开局配置非法（退出码 2）
E_CONTENT_*E_ENV_CONTENT_INVALID配表校验失败，原码进 detail
E_KERNEL_INVARIANT / EXCEPTION / DISPATCHE_ENV_INTERNAL内核异常或不变式违反（退出码 4）
E_KERNEL_RNG_*E_ENV_RNG未注册流名 / 区间非法
E_KERNEL_TURN_LIMIT—（不是错误）表现为 truncationReason="turn_limit"
E_ACTION_*原样保留非法动作，跨语言比对用

逐步校验已真的接上。从 2026-10-15 起，MOD-02 在每次提交前对未提交的新状态跑 assert_invariants；违反即 E_ENV_INTERNAL、该步不提交。训练路径同类累计 ≥3 次会中止 run，批量测量记 dropped——不再有“配置里写着校验、生产局从不执行”的死键。
