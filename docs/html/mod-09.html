MOD-09 infra

所有模块都踩在上面的地板：配置怎么合并、run 目录长什么样、事件怎么落盘、退出码怎么分、随机与 import 怎么被守卫、git 什么时候能提交。它自己不产生实验结论，但决定了结论可不可信。

L3 工程 ✅ 已落地 退出码 0–5 / 130 确定性守卫

01配置：五层合并，一个哈希

“同一 run 只能同族配置”。冲突时提示会给出键级漂移摘要（新增/删除/值变化各多少键并点名），但判定仍只看 config_hash——不提供“忽略漂移”的开关。
环境变量必须双下划线。DICERATCHET_ENV__SANDBOX__POLICY_FAILURE_STREAK 生效；写成单下划线会被静默忽略（且不报未知键）。短别名 POLICY__… 可用，但它只是别名。

02run 目录：一次实验的全部证据

runs/<run_id>/
├── config.json          # 配置快照 + config_hash + content_hash
├── state.json           # phase / generation / 队列 / 计数器
├── events.jsonl         # 结构化事件（唯一事件出口）
├── episodes/<split>/    # 逐局轨迹（每步一行）
├── reflections/         # 局末反思或 skipped 标注
├── memory/              # memory_active.jsonl + memory_v{N}.jsonl
├── generations/         # gen-NNN/report.json + candidates/ + patches/
├── metrics/             # generations.csv / arms/ / acceptance.json
├── plots/               # 5 张 PNG（必须由数据点）
├── prompts/             # ⚠️ 目录存在，但当前没有写入点
├── audit/               # leak-<scope>.json / harness-gate.json / env_error_*.json
└── llm_api/             # API 请求/响应 hash 与 usage（不含 key）
证据链的原则：先写轨迹并 flush，再写 state.json；计分台账按 episode_key 去重；报告写完后才写 .sha256 存档。崩溃最多丢当前决策，不会产生“半局计入”。

03退出码：两根正交的轴

码含义典型场景
0成功（含 HITL 挂起）跑完、正常挂起、判定器输出结论
1领域失败验收不达标、判定器 ok=false（但命令本身成功）
2配置 / 环境错误config 非法、run 冲突、未裁决起点
3模型不可用未知 model_id / 权重缺失 / 后端起不来
4沙箱 / 守卫违例脏工作区、import 越权、不变式违反、规则集钉扎不符
5IO 落盘失败磁盘满 / 写失败 / 绘图无数据
130Ctrl-C当前 step 落盘后中断，可 --resume
结论轴与守卫轴分开。audit leak 的 0/1/2 是“有没有泄漏”的结论轴；4 是“审计器自己不可信/环境不合法”的守卫轴。把两者混成一个码，会让“实验结论是否定”和“命令失败”无法区分。

04守卫：随机、分层 import、git

确定性守卫

scan_determinism()：禁未显式 seed 的 random/numpy.random、禁时间参与采样、禁 uuid4() 做标识。命中 → E_IO_GUARD_RANDOM（退出码 4）。

分层 import

scan_layer_imports()：L1+ 出现 import dice_ratchet.env → E_IO_GUARD_LAYER（INV-1）。例外必须写 # guard: allow … reason=… 并留痕。

git 门禁

起跑前 preflight_worktree_clean()：脏 → E_IO_GIT_DIRTY（退出码 4），0 推理。提交前 commit_harness() 再兜底一次。

事件注册

事件名必须登记在 EVENT_REGISTRY；未登记在 dev 抛 E_IO_EVENT_UNKNOWN，生产改写成 infra.unknown_event 并保留原名。

2026-10-17 修掉的一类真缺陷：有 8 个事件只 emit、未登记（evolve.start_guard、evolve.parent_inherit、evals.arm_reused 等）⇒ 生产里“留痕”实际丢掉了事件名。现在已全部登记，`evals.*` 经别名归一为 `eval.*`。
