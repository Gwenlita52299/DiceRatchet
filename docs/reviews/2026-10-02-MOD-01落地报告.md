## 关键设计点

- **逐位等价优先于 Pythonic**：64 位乘法用 16 位分片复刻 JS 的截断语义（其结果与标准 64 位乘法在 mod 2^32 下等价）；整除一律 `//`；字符串比较不依赖 locale。
- **写时拷贝**：合法动作 deepcopy 后修改、返回新 state；非法动作原对象返回。入参永不被修改（K-1），非法动作零副作用。
- **冻结配表 + thaw 边界**：`load_tables` 返回深度冻结视图（dict→MappingProxy、list→tuple）保证只读；`state.thaw()` 在任何把配表数据写入 state 的位置（敌人 slots/passives、锻造面）递归解冻，确保 state 始终是可 deepcopy/JSON 的纯数据。**该边界曾出现两处回归**（浅拷贝 slots、`list(passives)`），已由 `test_state_is_json_serializable` 固化。
- **守卫友好**：`random_skill` 改名 `pick_random_skill` 以避开确定性守卫的 `random.*` 前缀规则（守卫只 ban 随机模块，不 ban 函数名）。
- **golden 不可由 Python 生成**：所有快照由 `scripts/golden-gen.js` 生成；重构后重生成与提交版逐字节一致（git 无 diff）。

## 对下游的契约提示（MOD-02）

- `GameEngine.create(config)`：config 可为裸 `{difficulty, seed}`，`apply_difficulty` 会补齐默认开关与 stageCount；非法配置抛 `EnvError(E_ENV_CONFIG_INVALID)`（退出码 2）。
- `reduce` 对非法动作返回 `{illegal: True, code, reason, events: [...], state: <原对象>}`，**不抛异常**；`error` 键仅在不变式/分派异常时出现（此时 state 不变，该局应标 `degraded`）。
- `observe(state, "full")` 是唯一信息出口；`play_hints` 已按槽给出合法性与预览值，可直接做启发式 fallback。
