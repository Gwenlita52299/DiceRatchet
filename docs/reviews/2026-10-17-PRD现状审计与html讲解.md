## 0. 一句话

本轮把「文档里写的」和「代码里 actually 做的」逐模块对了一遍：**修掉约 100 处过期断言**，

## 1. 为什么现在做

2026-10-17 的协议口径纠正（P1 判负、`loop baseline`、起点守卫）之后，代码向前走了一步，
而 PRD 的“当前状态”段仍停在 10-15/10-16。继续按文档操作会踩到至少三类坑：

1. 按文档设的环境变量被**静默忽略**（`DICERATCHET_SANDBOX_*` 少一个下划线）；
2. 按文档找的产物不存在（`metrics/llm_calls.jsonl`、`inference_agg.json`、`honeypot.jsonl`）；
3. 按文档写的字段/命令会直接失败（轨迹行 `decision_source`、`loop run --eval-workers`、
   `evolve approve --generation` 缺 `--run-id`）。

## 3. 代码侧的两处缺口（已一并修）

1. **8 个事件只 emit 未登记**：`evolve.start_guard` / `parent_inherit` / `proposal_checkpoint` /
   `proposal_reused` / `dead_end` / `play_hash` / `evals.arm_reused` / `evals.generation_unresolved`
   等（`evals.*` 经别名归一为 `eval.*`）。生产模式会把它们改写成 `infra.unknown_event`，
   `DICERATCHET_DEV=1` 下直接抛 `E_IO_EVENT_UNKNOWN`——也就是说“留痕”本身不可靠。
   修法：在 `infra/events.py` 按 emit 处实际字段补登记（+4 个别名）。
2. **`schemas/generation_report.schema.json` 的 `decision` 枚举缺 `error_reject`**：
   真实产物（`runs/m3r2/generations/gen-002/report.json` 等）与 MOD-08 的 `VERDICT_DECISIONS`
   都会写这个值，但 schema 会拒。修法：枚举补 `error_reject`。

（`tests/integration/evolve` + `test_loop_closure` + `test_loop_env_isolation` +
`test_env_sandbox_contract`）**36 passed**；`guards check` 0 findings；`tests/integration/test_prd_paths.py` 3 passed。

## 4. `docs/html/`：11 页可视化讲解

定位与 2026-10-14 被删除的「手工 PRD 镜像」**不同**：

- 它不是规范文本的复制，而是**按当前代码重画的理解路径**（结构、流程、判据、现场状态）；
- 每页页脚标明源 commit 与生成日期；页面里的事实都能在代码/PRD 中找到对应；
- 纯静态、零依赖、可离线打开；共享 `assets/style.css` + `assets/app.js`。

页面：`index` + `game` + `mod-01..09`。入口 `docs/html/index.html`，维护说明见 `docs/html/README.md`。

**诚实边界**：这些页面的“当前状态”数字是 2026-10-17 的快照；判据/配置改动后必须同步页面。
若未来要长期维护，建议把“当前状态”段做成可复算的构建步骤（本轮未做）。
